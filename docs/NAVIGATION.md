# Разделы панели

- **Обзор:** суммарное количество подключений, недавняя активность по handshake,
  здоровье протоколов и карточки с портами. Кнопка карточки открывает клиентов
  соответствующего протокола.
- **Клиенты:** список подключений выбранного протокола, статистика, инспектор,
  создание и отзыв. Это единственный основной раздел управления.
- **Журнал:** до 100 последних транзакций панели на сервере: создание/отзыв,
  протокол, время начала, последний результат и непрозрачный ID клиента.
  События официального клиента не регистрируются панелью. Исторические записи
  не содержат имён, поэтому отображается ID, а не выдуманное имя.

Журнал читается через GET `/api/v1/journal`, в том числе в read-only режиме API.
Helper возвращает только явно разрешённые поля `state.json`; backup, ключи,
конфиги и служебные хэши не выдаются. Чтение не вызывает Docker, recovery или запись.
Повреждённые записи пропускаются с видимым счётчиком. При ошибке подключения UI
показывает ошибку, а не пустую историю. Обновление выполняется при открытии раздела
и кнопкой «Обновить журнал». Показанный статус — снимок, не поток событий.

В компактной боковой и мобильной нижней навигации видны подписи. На телефоне
операции представлены карточками, чтобы результат не скрывался за горизонтальной
прокруткой. Активный раздел также обозначен `aria-current`.
