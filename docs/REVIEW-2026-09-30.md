Read-only чтение через реальный `InventoryService` подтвердило AWG 2.x,

Панель по текущей архитектуре запускается локально на компьютере администратора;
на сервер требуется отдельно установить root-owned helper для управления.

## Исправленные находки

1. **P2: устаревший кэш после изменения.** Если изменение завершалось во время
   чтения списка, `invalidate()` могло быть перекрыто завершением этого чтения.
   Следующий запрос получал старый состав peer-ов из кэша. Добавлен счётчик
   поколения: чтение, пересекающее изменение, не получает новый срок кэширования.
   Уже начатый ответ может содержать прежний снимок, но следующий запрос перечитает сервер.
   Добавлен тест с управляемым пересечением чтения и invalidation.
2. **P2: SSH-процесс переживал отмену чтения.** Завершение процесса выполнялось
   только при timeout. Теперь отмена также завершает и дожидается процесса,
   сохраняя `CancelledError`. Добавлен тест отмены во время `communicate()`.
3. **P2: отменённый запрос изменял состояние интерфейса.** Старое чтение могло
   снять индикатор загрузки нового запроса; добавлены проверки отмены перед
   обновлением данных, ошибки и индикатора загрузки.
4. **P2: уязвимая зависимость инструментов разработки.** `brace-expansion`
   обновлена в lockfile с 5.0.9 до 5.0.12. После чистой установки полный
   `npm audit` сообщает 0 уязвимостей. Рабочие зависимости приложения не менялись.
5. **P3: незаметная ошибка копирования профиля.** Ошибка Clipboard API теперь
   перехватывается; интерфейс сообщает об успехе или предлагает скачать файл.
