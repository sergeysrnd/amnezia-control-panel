# Amnezia Control Panel

Приватная панель управления уже установленными официальными контейнерами Amnezia VPN.

## Цель

Панель обнаруживает существующие контейнеры и подключения, показывает их состояние и позволяет безопасно создавать, переименовывать, отключать и удалять клиентов. Она **не устанавливает, не обновляет и не пересоздаёт VPN-контейнеры**.

Поддерживаемая область первой версии:

- AmneziaWG legacy (`amnezia-awg`);
- AmneziaWG 2.0/3.1 (`amnezia-awg2`);
- WireGuard (`amnezia-wireguard`);
- импорт уже существующих peer-записей;
- runtime-статистика: handshake, RX/TX, endpoint, статус;
- создание совместимого клиентского конфига и QR-кода;
- резервная копия и откат каждой операции изменения.

## Принцип совместимости

Источником истины остаются официальные конфиги внутри контейнеров Amnezia. Панель не создаёт собственный VPN-стек и не меняет схему развёртывания Amnezia. Изменения применяются тем же механизмом, который использует официальный клиент: обновление конфигурации и `wg/awg syncconf`.

## Статус

Реализованы чтение и транзакционное управление подключениями:

- read-only FastAPI backend с allowlisted SSH/Docker transport;
- parser официальных конфигов, `clientsTable` и runtime dump;
- объединение существующих peer-ов с handshake и RX/TX;
- React dashboard с адаптивной таблицей, инспектором и сортировкой;
- интерактивный demo-flow создания подключения без записи на сервер;
- CI, backend-тесты, lint и production frontend build.
- создание/отзыв с backup, проверкой ревизии, атомарной заменой файлов и rollback;
- root-owned SSH helper с привязкой к container/image ID и журналом восстановления;
- реальные формы создания, одноразовый native `.conf`/QR и отзыв по подтверждённому имени;
- защита локального API от межсайтовой записи и повторных запросов.

По умолчанию API работает в режиме чтения. После установки helper и приёмки
режим управления запускается через `make dev-api-manage`.
На текущем сервере создание и отзыв проверены для AWG Legacy, AWG 2.x и WireGuard.
Импорт профилей в официальные клиенты, клиентский трафик и live AWG 3.1 — ещё не проверены.

## Важное ограничение

Панель рассчитана на локальный доступ одного доверенного администратора.
Официальный клиент не использует блокировку панели: не редактируйте подключения
одновременно из двух приложений. Установленные VPN-контейнеры не перезапускаются.

## Локальная разработка

Требования: Python 3.12+, `uv`, Node.js 24+, npm и работающий SSH alias до тестового сервера.

```bash
make install
make dev-api
```

Во втором терминале:

```bash
make dev-web
```

Открыть `http://127.0.0.1:5173`. Backend по умолчанию использует SSH alias `amnezia-server`; его можно изменить переменной `AMNEZIA_SSH_TARGET`.

Для полностью обезличенного интерактивного UI без обращения к серверу:

```bash
cd frontend
VITE_DEMO_MODE=true npm run dev
```

Все проверки:

```bash
make lint test build
```
